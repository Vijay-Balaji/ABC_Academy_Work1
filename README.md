# ABC Academy — 3-Site No-Code Admin

## Pages
- `index.html` — Interest / start page
- `education.html` — Education & Courses
- `services.html` — Fashion & Beauty Services
- `admin.html` — One admin dashboard for all three pages

## Admin
Open `admin.html` and enter the demo PIN `1234`.

The dashboard has four simple choices:
1. Interest Page
2. Education
3. Services
4. Common

The client can edit text, add/remove courses and services, change popup details, add carousel slides, add portfolio images, update alumni, testimonials, reviews, YouTube video and Google Map.

## Images
For permanent GitHub images, add files to `assets/images/` and enter the relative path in the admin field, for example:
`assets/images/new-bridal-photo.jpg`

Uploading a file directly inside the browser stores it in that browser only. It does not upload to GitHub.

## Important
This is a static no-code editor using browser localStorage. Changes are available in the browser where they were saved. If the client needs changes to update the live Netlify/Render website for every visitor and from multiple devices, connect the admin to a real backend/CMS such as Supabase/Firebase or a GitHub-backed CMS.
